# Progress: 10 Nov 2026, phase 2: the status mark

Phase 2 of `docs/plan.md` (the mascot and sprite packs, `CLAUDE.md` §8), built in a worktree
beside phase 1 (session tiles). Midway, Colin changed the brief: the default status mark is no
longer a dot or the fox but **the Knot**, an animated (3,4) torus knot coloured by the theme,
small and slow at rest, full size and fast at work; sprite packs (Foxtrot recommended) are what
a user installs over it. §8 now describes what exists; this file records how it was checked and
what is open.

## Decisions to confirm

1. **Status → Knot** (the table in §8): rest 0.5 size / 22 s loop / 6 fps; work 1 / 2.4 s / 30 fps;
   needs-you 0.85 / 7 s / 15 fps in the theme's blocked colour (so it does not rely on speed);
   starting 0.75 / 5 s; dead 0.5, still, dimmed. A bark flares the pulse and swells the knot 12%
   for 0.9 s.
2. **Status → sprite pose**: starting and unknown → idle; busy → run; idle → sleep; blocked or
   attention → look; dead → sleep, dimmed. (deck used look for starting and sleep only for idle;
   §8's table says idle for starting, which is what is built.)
3. **Where a tile's bark lands**: the session that called that tile through the door in the last
   10 minutes, else the focused one, else nowhere.
4. **Recognising Elthen's sheet** by layout only: 448 × 224 and the frames per row (5, 14, 8, 11,
   5, 6, 7) counted from transparency. No pixels, no hash. A different sheet with exactly that
   layout would be mapped as the fox; it can be edited.
5. **The two coat colours** (`#d67941`, `#9d5021`, from deck) are in the Foxtrot mapping for the
   worker swap. They are facts about the art, not the art; drop them if Colin prefers, and the
   default gold tint applies.
6. Contrast is checked against the panel and the window background, not the selected row's
   `--ws-line` highlight; by eye it reads there too (screenshots below).

## How it was checked

- `npm test`: 131 passed (88 before; new: `mascot.test.ts` 18, `knot.test.ts` 24, settings 1).
- `npm run smoke`: 154 passed, 0 failed (135 before). New checks: the Knot on a session with no
  pack and no dot; drawn; the app mark at the top left; its mode follows status (needs → rest →
  work); a turn finishing flares it; `notify({ bark: true })` flares it; a synthetic pack replaces
  it, poses follow status, Leap plays once and the pose returns; removing the pack brings the Knot
  back; the setup screen recommends Elthen's fox with the licence lines and recognises a synthetic
  sheet with his layout, mapping all five poses.
- Contrast (worst drawn colour, against panel and background, across every mode): every variant
  reaches 3:1. Theme colours that fell short and were moved toward the ink: cream light busy,
  cream dark dead, solarized light busy and muted, solarized dark dead, gruvbox light accent and
  busy, gruvbox dark dead, catppuccin light busy and muted, nord light busy and starting, nord
  dark dead, graphite light busy and blocked, graphite dark dead, glass light busy, glass dark
  dead. Catppuccin dark and Deep Space needed nothing.
- CPU (`WORKSHOP_MEASURE_CPU=1`, the smoke window, ten sessions plus the app mark, no terminal on
  screen, renderer process only, 10 s each): resting 0.8%, working 1.0%, working with every Knot
  off screen 0.7% of one core. The smoke window is never shown, so compositor and GPU-process
  cost is not in these numbers.
- By eye: session heads and the top-left mark in Deep Space, Gruvbox light and Nord dark; the
  setup screen; and Elthen's sheet loaded from deck's copy into a throwaway smoke profile
  (recognised, every pose right, sleep drawn crisp in the head). Those pictures stay in the
  session's scratchpad, never in the repo.

## Not verified

- That the clocks stop when the real window is hidden: the code stops on `visibilitychange`, but
  smoke's window is never shown, so smoke cannot hide it.
- Reduced motion (one still frame) was not exercised.
- Dropping a file by drag (the smoke uses the file input); Electron's drop path is the same event.
- The real `claude` CLI driving the marks (the stand-in drove them).
